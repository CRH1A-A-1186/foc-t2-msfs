## 2. 屋面（r6）——为什么这么建

### 2.1 问题

旧屋面（r4/r5）是「檐口环 → 收缩环」两环放样，底面用一张**水平封盖**收口：
截面因此是一个**高 14 m 的厚楔块**，不是照片里那条**薄弯板**。
想把它改薄时，用「往里再缩一圈」得到的第二层曲面在**凹角**（中庭缺口、翼尖转折）会折进去打穿上表面 —— 实测 18–23 处自交，不过门。

### 2.2 现在的做法（`tools/build_roof.py`）

1. **高度场**：屋面写成单值函数 `z = f(x, y)`，数学上不可能自交。
   ```
   z = TOP_EAVE + ( R(p)·g(u) + tip_up(p)·g(u) )·,  u = d / D(p)
   d  = 到檐口轮廓的距离（同一个场 → 全楼一张连续壳，没有拼缝）
   D  = 各体量实测半宽（大厅 72.24 m，指廊 81.24 m）
   g  = smoothstep（檐口与屋脊处斜率为 0）
   ```
   - 檐口 12 m 内是**平直挑檐**（`g=0`），所以外挑段是一条水平薄板 —— 对应照片里的「大悬挑」；
   - `R`：大厅 12.35 m（脊高 27.35→39.70 m），指廊 5.50 m，翼尖再 +3.00 m 上翘。
2. **等厚偏移**：同一高度场整体**竖直下移 1.40 m** 得到下表面（不是沿法线偏置 —— 竖直偏移保证上下两张单值曲面永不相交）。
3. **檐口封边**：只把「只用了一次的边」（= 外轮廓）拉出 1.40 m 高的竖直檐板，壳闭合。
4. **精确保轮廓**：屋面轮廓不是栅格阶梯 —— 每个栅格单元用 shapely 与真实檐口多边形求交后再三角化，交点在 1 mm 内焊接，所以檐口线严格贴轮廓，无 T 型接缝。
5. **光滑**：原始距离场在**中轴脊线**处有折痕（脊会分叉，看着像凹坑），做 12 次拉普拉斯松弛把折痕圆成一个脊；檐口环**钉住不动**（保证轮廓与板厚精确），最后把脊高重新归一化回 39.70 m。

## 3. 坐标与摆放（MSFS）

- 原点 = ZSFZ ARP **25.929254 N / 119.672524 E**（OurAirports，标高 46 ft）。

## 6. 已知限制 / 下一步

1. **光伏采光带（r5 的 GEO-T2-pv）本版删掉了**：r5 里它是一张平面四边形，`d` 全是 0，实际埋在旧厚屋面内部（不可见）；放到新曲面上会浮起/穿刺，必须按松弛后的高度场重新做成贴合面片 —— 留到下一版。
2. **没有檐口格栅/镂空板、幕墙竖挺、登机桥、陆侧雨棚、屋顶设备**。
3. **道面覆盖有空洞**：OSM 的 apron/taxiway 多边形之间有空隙，地形底板会从缝里露出来（见 r6_cam-iso.png 的浅灰碎片）。导出前要把道面补成连续覆盖。
4. 未包含 T1、货运、GTC、塔台、机位标线与灯光。
5. 滑行道统一 23 m；跑道 04/22 按与 03/21 平行建模，04 号内移 200 m 未单独建模。
6. 无 LOD、无碰撞体、无贴图（纯色 PBR）。

## 7. 复现

```powershell
# 1) 几何（需要在 Blender 自带 Python 3.13 下跑，用 cp313 的 shapely/numpy）
blender -b -P tools\run_geo_roof.py          # build_geo.py -> geo.json, build_roof.py -> roof.json
# 2) 场景
blender -b -P build_scene.py                 # -> build/foc-t2.blend
# 3) 验图（读 .blend 里的 5 个机位）
blender -b build\foc-t2.blend -P tools\qc_render_r6.py
# 4) r7 才做：tools\export_glb.py -> out\foc-t2.glb + tools\verify_glb.py
```

`tools/pylib313/` 是给 Blender 5.3 的 Python 3.13 用的 shapely 2.2.0 + numpy（cp313 wheel）；
`tools/pylib/` 里的 cp312 版本在 Blender 里无法加载（`No module named 'shapely.lib'`）。

## 9. 显示异常（2026-11-26 修复，仍有效）

| 症状 | 原因 | 修复 |
|---|---|---|
| 视口里模型被切成几块、边缘直线切断；**每次重开文件看什么都不全** | 3D 视口的 clip 是 0.1 / 1000 m（工厂默认），模型跨度 4.4 km；而且它存在 View3D 空间里、不在场景里，重建 .blend 就回到默认 | `build_scene.py` 的 `fix_view()` 把**每个工作区**的视口写成 clip 1 m / 80 km，并把视点停到 T2 上（否则新开文件盯着原点，模型在 250 m 外，看着是空的） |
| 竖向 z-fighting 条纹（机坪上一块块亮斑、跑道标线断成虚线） | ① 近裁剪面 0.1 m ⇒ 1 km 处深度精度只有 ~0.9 m，而层间只差 0.2–1.4 m；② 道面分块时「机坪 = 机坪 − 跑道 − 滑行道」产生了**带洞多边形**，导出时只写了外环 ⇒ 机坪又盖回滑行道，**同 z 共面重叠** | ① 近裁剪 1 m（1 km 处精度 ~0.09 m）；② `rings()` 现在把 `holes` 一起导出，`flat_multi()` 用 `bmesh.triangle_fill` 做环形填充（外环 + 洞一起填），机坪不再盖住滑行道；③ 地形底板下移到 −1.00 m，标线上抬到 0.30 m |
| 屋面/地面锯齿状黑斑 | 2° 太阳光在 4 km 平面上产生 shadow acne | 太阳光关阴影、角度 9°；`scene.eevee.use_shadows=False` |

判据：`out/renders/r6_userview_check.png`（1.25 km、抬高 700 m，与用户视口同机位）里机坪无亮斑、无条纹，檐口与幕墙不打架。
